# Proven Regression Patterns

Use this as a cause map, not a substitute for inspecting the failing PDF.

| Symptom | Proven cause | Guard / regression location |
| --- | --- | --- |
| GUI stops at the last page on a large book | Unused dual PDF doubled pages; font subsetting and `garbage=3` recompressed the whole document while holding the GIL | Mono-only app path and large-document thresholds in `high_level.py`; `test_large_document_finalization.py` |
| Whole page appears upside down | A visually upright source used a reflected `1 0 0 -1` text matrix with negative font size; reflection was mistaken for rotation | Classify from baseline and normalize reflection; orientation tests |
| Rotated heading becomes one glyph per line | Source 90-degree baseline was rebuilt as horizontal text | Quarter-turn grouping/rendering in `converter.py`; orientation/style tests |
| Bold or italic disappears | Translation collapsed every run into the regular font | Validated `<s1..3>` pairs, variant selection, synthetic fallback tests |
| Formula moves, overlaps, or exposes `{vN}` | Ordinary-font math was translated as prose or translator damaged placeholders | Formula regions, stacked fraction detection, safe tag round-trip tests |
| Table labels stay English | Earlier pipeline protected the entire model table | Translate only matched cells; preserve unmatched tables and technical codes |
| Paragraph crosses the right edge | Width budget ignored first-line indentation | `paragraph_width_budget()` regression |
| Last table line crosses a row | Font shrank after ink was measured, or preserved code remained larger than prose | Recompute final ink, fit union, then shift inside cell bounds |
| Bullets vanish on Mac or Windows | Office encoded Wingdings/Symbol bullets as PUA characters absent from Go Noto and Times New Roman | `is_bullet_character()` preserves the embedded dingbat glyph; preservation tests |
| Translation service corrupts style/formula tags | Tags are translated, dropped, duplicated, or cross-nested | Reject segment, keep source, report partial; handoff translator tests |
| Vietnamese loses every stacked-diacritic letter ("Việt" renders as "Vi t") | `subset_fonts(fallback=True)` renumbered glyphs while the content stream addresses them by raw ID; only bit documents under the 200-page/50 MiB threshold | `should_subset_fonts` returns False; `test_large_document_finalization.py` |
| Lines of one paragraph print through each other | Leading was compressed to 0.75 against Vietnamese ink needing 1.10 em | `min_line_height_for_language`; `test_preservation_rules.py` |
| A paragraph prints over the one below it | Only its own box was the budget, and prose had no ink guard | `available_height_below` plus the prose fit loop; `test_inline_formula_layout.py` |
| A whole bullet list stays in English and sprawls over its neighbours | The bullet's tab set the paragraph size, so the body looked like a subscript and was preserved as a formula | `size_should_follow_body`; `test_inline_formula_layout.py` |
| A structurally damaged PDF fails while pikepdf opens it fine | Repair was gated on pikepdf rather than on the engine's own round trip | `pymupdf_can_round_trip`; `test_large_document_finalization.py` |
| The packaged macOS Intel app dies before the first page | cryptography 49.0.0 dropped the macOS universal2 wheel, so Intel compiles it against Homebrew's OpenSSL while PyInstaller bundles Python's older `libssl.3.dylib` (`Symbol not found: _SSL_get0_group_name`) | Intel-only pin in `requirements.txt`; `verify_engine()` in the packaged `--smoke-test` |
| An image-only scan is delivered as a finished translation | The scan was detected but the result never left the engine, and `is_scanned_page` only fires when one image covers half a page, which tiled scans never do | `page_has_image` plus `image_only_pages`; the no-extractable-text refusal in `translate_pdf.py`; `test_preservation_rules.py`, `test_translate_pdf.py` |
| A page that did translate is reported as an untranslated scan | `receive_layout` runs once per nested container and only the last call carries the text, so the page was judged before its own content arrived | Accumulate `segments_by_page`, decide `image_only_pages` at the end; `test_preservation_rules.py` |
| Every skipped segment tells the user their network is down | The skip reason reached `record_translation_failure` and was logged, then dropped; only a count travelled up | `TranslationReport.reasons` through `high_level.py`; `_describe_failures`; `test_translate_pdf.py` |
| A user cannot read or report the error they were shown | The detail label starved the filename column and clipped; no code, no log pointer | `app/errors.py` codes and the row detail dialog; `test_app_errors.py` |
| Letters pull apart inside a word and the line stops short of the right margin | The paragraph shrank to fit its box after its operations were built, and only the font size was scaled; every run stayed at the coordinate the old size had produced. Vietnamese starts a new run at each accented letter, so the gaps landed inside words | `rescale_operations` re-places runs from the start of their line; `test_inline_formula_layout.py` |
| Every bold term in a paragraph prints on top of the prose around it | The producer parks stray glyphs above the page between styled runs. They match no layout region, take the catch-all class, and the class change starts a new paragraph, so each fragment reflowed inside its own width | `is_outside_page` drops glyphs entirely off the page; `test_inline_formula_layout.py` |
| A list marker or symbol comes out blank and extracts as U+0000 | `raw_string` writes `has_glyph()` straight into an Identity-H font, and a character the prose font lacks is glyph 0, which draws as .notdef | `output_font_lacks_glyph` makes `vflag` keep the source glyph; `test_inline_formula_layout.py` |
| Coloured headings come out black | Translated runs stated no colour, so they took the black a content stream starts in | The colour in force travels with each glyph and is replayed per run; `test_inline_formula_layout.py` |
| A blue heading is drawn white on white paper | `0 0 0 1 sc` is CMYK black, but replayed without the `cs` that named its space it reads as the one component of DeviceGray, and DeviceGray 1 is white | A device space is supplied from the operand count, and a colour that still cannot be explained is dropped so the run falls back to black; `test_inline_formula_layout.py` |
| Italic runs come back regular | Emphasis was guessed from the font name, and the Adobe Pro families abbreviate the slanted face (`MinionPro-It`, `MyriadPro-BoldIt`) | `text_style_from_descriptor` reads the descriptor's own flags first; `test_inline_formula_layout.py` |
| A whole column reflows as one block, and short lines run together | The layout model returns a column, not a paragraph, and nothing else said where one stopped | `line_ends_paragraph` splits on a line that stops short of its column, as BabelDOC splits on the page median; `test_inline_formula_layout.py` |
| A figure caption stays in the source language | Its bold label is set larger than its body, so the body read as a subscript against it and was preserved | `run_is_prose` puts a long run of words back into the paragraph; `test_inline_formula_layout.py` |
| The tail of a long paragraph disappears | Google's endpoint takes 5000 characters and the translator sent the first 5000 of anything longer, returning that as the whole translation | `SegmentTooLongError` refuses it and `_describe_failures` reports it as its own reason; `test_handoff_translator.py`, `test_translate_pdf.py` |
| `ref. no. 305` becomes `ref. KHONG. 305` (both builds) | Lowercase `no.` mid-sentence reads as the negation to every engine we can reach; capitalised it is unambiguous | `normalise_number_abbreviation` in `pdf2zh/translator.py` and `SourceTextNormaliser` on Android; `test_handoff_translator.py`, `SourceTextNormaliserTest` |
| A translated sentence says something the source did not ("advanced equations" becomes "advanced equipment") | Android sent one extracted line at a time, so the engine translated a fragment as if it were the whole thought | `groupIntoParagraphs` joins lines into the sentence before translating; `drawParagraph` writes it back onto the source baselines; `PdfLayoutPreserverTest` |
| OCR output destroys a scan's formulas, form grid, or coloured artwork | Partial inpainting trusted fragmented OCR boxes and redrew them over protected structures | Experimental `pdf2zh.ocr` now preserves a whole page when layout, rules, formula/numeric density, or OCR fragmentation is unsafe; only explicit safe prose pages are cleaned |
| OCR text overlaps its source, emits U+0000 for a bullet, or starts from mojibake | The glyph mask missed anti-aliased rims, standalone U+25CF travelled through the prose font, or the recogniser returned damaged characters on a dense page | OCR dilates the final safe-page mask and verifies residual ink; standalone markers stay in the raster, while mojibake and pages without reflow headroom are preserved whole (`test_ocr.py`) |
| OCR translation sends code or unowned multi-column prose through the reflow path | A sidecar line has no explicit column ownership and the converter can attach continuation blocks to a later region | Code stays protected; multi-column/dense prose now requires explicit approved paragraph bounds, covered by `test_ocr.py` |
| OCR splits every NASA body line into a paragraph and shrinks a short tail to 4.7 pt | Sidecar font was about 8 pt but source baselines were 13 pt apart, triggering the ordinary 1.5-em paragraph-gap heuristic | OCR-owned paragraphs bypass font-derived break heuristics; source ink gaps and raster bullets supply boundaries; full-pipeline three-lines-to-one-paragraph regression |
| Postal-address lines overlap despite passing canvas checks | A glyph's descender origin falls into the next line's padded OCR region; two halves of one row receive different classes | Choose owned OCR classes at glyph centres; merge adjacent baseline fragments; preserve postal rows and prose indentation; NASA1999 coordinate regression |
| A text PDF leaves isolated `N` and `f` where `Note` and `fluxes` begin | Approximate model text region starts at x=67.3 but the word starts at x=63.36 | Recover catch-all edge glyphs from significant glyph-box overlap, never override protected formula/table pixels; `test_inline_formula_layout.py` |
| Historical scans detect only two tiny text fragments | OCR raster height was passed as DocLayout inference size (4445 px) | Cap layout inference at 1024; keep recognition at its own DPI; large-scan resolution regression |
| A zero-missing-segment report hides unreadable output | Handoff coverage and canvas checks cannot detect two in-canvas lines drawn over one another | `audit_translation.py` reports overlap candidates, with manual rendered-page review still mandatory; unchanged scans are not translation success |
| A protected form shifts labels and loses horizontal rules | Protected glyph placeholders still entered the prose fit loop and rules were detached for formula reflow | Replay protected source glyph matrices/size/scaling/rise and retain protected grid operators; exact-raster form regression in `test_ocr.py` |
| Retained dashed form borders change their dash lengths | Python list serialization introduced commas into the PDF `d` array operand | `graphic_operand` writes whitespace-separated arrays; protected-form raster regression includes `[1 2] 0` dashes |
| Old-paper cleanup remains checkerboard despite a new paper estimator | Dense line masks leave too few nearby blank samples and reject the entire estimate | Bounded adaptive sampling with one shared scale, dense-band and no-support regressions in `test_ocr.py`; residual band edges remain a disclosed visual limitation |
| An ordinary two-column textbook scan is refused as a form | Its two section-heading underlines satisfied a blanket `rule_count >= 2` guard | Distinguish heading rules from grids: protect 3 horizontal, 2 vertical, or a crossing pair; Ganong page 346 and synthetic rule regressions |
| A protected landscape appendix turns sideways inside an already landscape page | `/Rotate 90` content was decomposed and replayed as glyph operators despite the whole page being protected | Keep the original stream when the layout mask is entirely protected; rotated index/form regression and Ganong page 727 |
| A table caption ends in `secretio` and a separate `n.a` fragment | The model caption box ended 14 pt before `secretion.` plus its superscript footnote | Recover an unambiguous catch-all suffix only from the region immediately to its left; never pull a gutter glyph forward; Ganong page 464 coordinate regressions |
| Range dashes and copyright symbols render as `â€“` and `Â©` | A handoff JSONL crossed a Windows-1252/UTF-8 display boundary | Repair a small allowlist of unambiguous punctuation in source keys and translations; handoff and audit regressions |
| A translated heading wraps with a lone `2` on a third line | Width fitting met the box budget but greedy wrapping left a short numeric orphan | For title-size text only, retry wrapping with up to four bounded 4% reductions; `balanced_wrap_positions` regression |
| A rotated page passes visually but the audit reports text outside the canvas | PyMuPDF span boxes use unrotated crop coordinates while `page.rect` reflects `/Rotate` | Audit against crop-box width/height in text coordinate space; rotated audit regression |

When adding a new guard, reproduce the smallest failing geometry in a unit test
and validate the real document visually. Do not encode a filename-specific fix.
